# 爱情故事博客 / Love Story Blog

这是一个使用 React + TypeScript + Vite 构建的爱情故事博客网站。网站收录了多个温馨浪漫的故事，以优雅的方式呈现给读者。每个故事都经过精心编写，带给读者独特的阅读体验。

## 在线预览

访问 [Love Story Blog](https://love-story-blog.vercel.app) 体验网站

## 项目特点

- 🚀 使用现代化的技术栈：React 18 + TypeScript + Vite
- 🎨 精心设计的UI界面，支持亮色/暗色主题
- 🌏 支持中英双语故事内容，满足不同读者需求
- 📱 响应式设计，完美适配PC/平板/手机等多种设备
- 🎵 优雅的背景音乐，提升阅读体验
- ❤️ 支持故事点赞、收藏和分享功能
- 🔍 支持故事搜索和分类浏览

## 技术栈

- **前端框架**：React 18
- **开发语言**：TypeScript
- **构建工具**：Vite
- **UI组件**：Ant Design
- **样式解决方案**：TailwindCSS
- **路由管理**：React Router
- **状态管理**：React Context

## 本地开发

### 环境要求

- Node.js 16.0.0 或更高版本
- npm 7.0.0 或更高版本

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## 部署

本项目可以部署在任何支持静态网站托管的平台，如 Vercel、Netlify、GitHub Pages 等。
